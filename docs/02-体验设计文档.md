# HomeMedicineBox MVP 体验设计文档

## 1. 设计目标

当前版本先做可用的本地录入 MVP。体验目标是减少用户手动填写压力，只保留完成家庭药箱和关键就诊记录所需的信息。

设计原则：

- `少填`：用户只填当前确实需要的信息。
- `本地优先`：不展示账号、同步、云备份入口。
- `直接可用`：首页、药品、就诊、设置四个入口清晰稳定。
- `识别增强`：医院、科室、医生等低频字段由后续识别能力带出，不要求用户手填。

## 2. 一级结构

| 一级入口 | 目标 | 关键内容 |
| --- | --- | --- |
| 首页 | 查看家庭药箱状态 | 成员切换、提醒统计、最近药品、最近就诊 |
| 药品 | 管理药品和库存 | 列表、新增、详情、编辑、减少库存、删除 |
| 就诊 | 记录关键就诊事件 | 列表、新增、详情、删除 |
| 设置 | 查看说明 | 本地存储、隐私、后续 AI 说明 |

当前版本不提供草稿入口。

## 3. 全局规则

### 3.1 成员切换

- 首页顶部展示当前成员。
- 默认成员为“家庭共用”。
- 切换成员后，首页、药品和就诊列表联动刷新。
- 非“家庭共用”成员查看药品时，也展示家庭共用药品。

### 3.2 新增入口

- 首页提供“新增药品”和“新增就诊”快捷入口。
- 药品页和就诊页分别提供对应悬浮新增按钮。

### 3.3 状态标签

| 场景 | 状态 | 展示位置 |
| --- | --- | --- |
| 药品批次 | 正常 / 即将过期 / 已过期 / 库存不足 / 已用完 | 药品列表摘要、药品详情 |
| 就诊事件 | 已记录 | 就诊列表、就诊详情 |

## 4. 信息架构

```text
HomeMedicineBox
├── 首页
│   ├── 成员切换
│   ├── 首页统计
│   ├── 今日提醒
│   ├── 最近药品
│   └── 最近就诊
├── 药品
│   ├── 药品列表
│   ├── 新增药品
│   ├── 药品详情

│   ├── 就诊列表

    ├── AI 识别说明
    └── 隐私说明
```

## 5. 核心流程

### 5.1 新增药品

1. 用户点击“新增药品”。
2. 选择成员。
3. 填写药品名称、规格、剂型、数量、单位、有效期、低库存阈值。
4. 可选填写用途/适应症、储存说明。
5. 保存后返回药品列表。

页面规则：

- 必填项为空时不能保存。
- 保存后立即刷新列表。
- 药品和首个批次一次性创建。

### 5.2 药品详情

详情页展示：

- 药品名称
- 规格
- 剂型
- 用途/适应症
- 储存说明
- 批次数量、单位、有效期
- 提醒状态

操作：

- 减少库存
- 编辑基础字段
- 删除药品

删除前必须二次确认，并说明批次会同步删除。

### 5.3 新增就诊

手动新增就诊只展示轻量字段：

- 成员
- 就诊日期
- 诊断/问题摘要
- 备注/文档摘要

不展示以下输入项：

- 医院名称
- 科室
- 医生姓名

原因：这些信息适合由后续诊断报告、处方或检查报告识别自动带出。普通用户手动记录时没有必要被要求填写。

### 5.4 就诊详情

详情页展示：

- 诊断/问题摘要
- 就诊日期
- 备注/文档摘要

如果数据中存在识别结果，则只读展示：

- 医院名称
- 科室
- 医生姓名

没有识别结果时不展示占位文案。

操作：

- 删除就诊记录

删除时同步删除关联文档摘要。

## 6. 页面细节

### 6.1 首页

| 模块 | 说明 |
| --- | --- |
| 成员切换 | 下拉选择成员 |
| 快捷操作 | 新增药品、新增就诊 |
| 首页统计 | 即将过期、已过期、库存不足 |
| 今日提醒 | 展示异常批次 |
| 最近药品 | 最近 3 条药品记录 |
| 最近就诊 | 最近 3 条就诊记录 |

首页不展示草稿数量或草稿卡片。

### 6.2 药品列表

- 空状态：`暂无药品`。
- 列表项展示药品名称、规格、批次数量和摘要状态。
- 点击进入详情。

### 6.3 就诊列表

- 空状态：`暂无就诊记录`。
- 列表项主标题展示诊断/问题摘要。
- 副标题默认展示就诊日期。
- 如果记录中已有医院或科室，则追加显示，不显示“未填写医院”。

### 6.4 设置页

当前设置页用于说明：

- 本地健康资料保护。
- 后续 AI 识别行为。
- 当前版本不提供账号和同步。

## 7. 后续识别体验原则

后续拍照和 AI 识别上线时：

- 识别字段只用于减少录入成本。
- 医院、科室、医生姓名等信息如果识别到了就保存展示。
- 没识别到时不强制用户补填。
- 用户仍需确认后才能保存正式记录。
